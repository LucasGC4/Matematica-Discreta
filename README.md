# Práctica de Aritmética Modular — IMAT

Repositorio de la práctica de aritmética modular para la asignatura de Matemática Discreta en el Grado en Ingeniería Matemática e Inteligencia Artificial (IMAT), ICAI — Universidad Pontificia Comillas.

## 📌 Resumen del Proyecto

Implementación y optimización de una librería matemática en Python (`modular.py`) y su correspondiente intérprete de comandos (`imatlab.py`) orientados al cálculo eficiente en álgebra modular y teoría de números.

Entre sus funcionalidades principales se incluyen el test de primalidad de Miller-Rabin, factorización mediante ruedas de primos, algoritmo de Euclides y Bézout extendido a listas, exponenciación binaria rápida, función $\varphi$ de Euler, símbolo de Legendre y resolución de sistemas de congruencias lineales con módulos necesariamente coprimos.
